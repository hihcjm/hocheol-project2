================================================================================
🎨 색상 및 평가 기준
================================================================================

Z-Score 5단계:
├─ z ≤ -2       : 극저평가 (진초록) - 매수 신호
├─ -2 < z ≤ -1  : 저평가 (초록) - 약한 매수
├─ -1 < z < +1  : 적정가 (파랑) - 중립
├─ +1 ≤ z < +2  : 고평가 (주황) - 약한 매도
└─ z ≥ +2       : 극고평가 (빨강) - 매도 신호

차트 색상:
├─ 파란 실선: 과거 5년 데이터
├─ 빨간 점: 현재값
├─ 보라 점: 컨센서스 (선택)
├─ 초록 점선: 평균선
├─ 주황 점선: ±1σ 밴드
└─ 빨강 점선: ±2σ 밴드

================================================================================
🚀 빠른 시작
================================================================================

1. 열기
   → index.html을 브라우저 더블클릭

2. 입력
   → 티커명 + 5년 데이터 + 현재값 입력

3. 저장
   → "저장" 버튼 클릭

4. 분석
   → 차트 + 통계 결과 자동 생성

5. 관리
   → 사이드바에서 여러 종목 관리

### 📊 js/stats.js
**목적**: 통계 계산 (순수 함수)
- Statistics 클래스
  - mean() - 평균
  - stdev() - 표준편차
  - zScore() - Z-Score
  - interpretZScore() - 평가 해석
  - getBands() - 표준편차 밴드
  - calculate() - 통합 계산

**특징**:
- 모든 메서드가 순수 함수
- 부수 효과 없음
- 테스트 용이

**공식**:
```
평균: μ = Σ(v) / n
표준편차: σ = √(Σ(vi - μ)² / n)
Z-Score: z = (v - μ) / σ
```

---

### 📈 js/charts.js
**목적**: Chart.js 래퍼 및 차트 렌더링
- ChartManager 클래스
  - createChart() - 개별 차트 생성
  - updateAll() - 3개 차트 동시 갱신
  - clearAll() - 차트 정리

**특징**:
- Chart.js 4.4.0 CDN 사용
- 데이터셋 기반 구조
- 실시간 업데이트 지원

**차트 구성**:
- 과거 데이터 (파란 실선)
- 현재값 (빨간 점)
- 컨센서스 (보라 점)
- 평균선 (초록 점선)
- ±1σ 밴드 (주황 점선)
- ±2σ 밴드 (빨강 점선)

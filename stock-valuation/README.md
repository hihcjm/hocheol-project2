# 📊 주식 가치평가 도구

주식투자의 가치평가를 위한 웹 애플리케이션입니다. 5년간의 PER/PBR/PSR 데이터를 입력하고 표준편차 밴드를 활용한 지표 분석을 수행할 수 있습니다.

## 🎯 주요 기능

### 1. 데이터 입력
- **티커명/종목명**: 분석할 종목 입력 (예: AAPL, 삼성전자, TSMC)
- **자동 데이터 조회** (NEW): 미국 주식(AAPL, GOOGL 등) 입력 후 엔터/탭 → Finnhub API에서 자동으로 현재 PER/PBR 조회
- **과거 5년 데이터**: PER, PBR, PSR 연도별 입력 (API 미지원 - 수동 입력)
- **현재값**: 현재 주가 기반 지표값 입력 (해외주식은 자동 조회 가능)
- **컨센서스** (선택): 애널리스트 컨센서스 예측값 입력 가능

### 2. 자동 통계 계산
- **평균(μ)**: 5년 데이터의 평균값
- **표준편차(σ)**: 데이터 분산도 측정
- **Z-Score**: 현재값의 통계적 위치 계산
  - Z ≤ -2: 극저평가 (진초록)
  - -2 < Z ≤ -1: 저평가 (초록)
  - -1 < Z < +1: 적정가 (파랑)
  - +1 ≤ Z < +2: 고평가 (주황)
  - Z ≥ +2: 극고평가 (빨강)

### 3. 차트 분석
세 개의 독립 차트 제공 (PER, PBR, PSR):
- **과거 데이터**: 파란 실선
- **현재값**: 빨간 점 (마지막 연도)
- **컨센서스**: 보라 점 (옵션)
- **평균선**: 초록 점선 (μ)
- **±1σ 밴드**: 주황 점선
- **±2σ 밴드**: 빨강 점선

### 4. 결과 패널
각 지표별 카드:
- 평균, 표준편차
- Z-Score 및 평가 등급
- 게이지 바 (-2σ ~ +2σ 범위에서 현재 위치 시각화)

### 5. 데이터 저장 및 관리
- **LocalStorage 자동 저장**: 새로고침 후에도 데이터 유지
- **티커 목록**: 사이드바에 저장된 종목 표시
- **빠른 로드**: 티커 클릭 시 즉시 데이터 복원
- **개별 삭제**: 각 티커 오른쪽 삭제 버튼

### 6. 엑셀 다운로드
SheetJS를 활용한 .xlsx 파일 생성:
- **Sheet1**: 입력 데이터 (연도별 지표값)
- **Sheet2**: 통계 결과 (평균, 표준편차, 밴드값, Z-Score)

### 데이터 입력 단계

#### 방법 1: 미국 주식 (자동 데이터 조회) ✨
1. 티커명 입력 (예: "AAPL", "GOOGL", "TSLA")
2. 탭 또는 엔터 키 → Finnhub API에서 자동으로 **현재 PER/PBR 조회** 💡

2. 5년간 PER, PBR, PSR 값 **모두 수동 입력**
3. 현재값 입력 (최신 데이터)
4. 필요시 컨센서스 토글 후 예측값 입력
5. "저장" 버튼 클릭 → 자동으로 차트 생성 및 통계 계산

- **미국 (나스닥/뉴욕)**: AAPL, GOOGL, MSFT, TSLA, META, NVIDIA, ...
- **유럽**: SAP, ASML, ...
- **기타**: TSMC (대만), ...
- **한국 주식**: ❌ 미지원 (수동 입력 권장)

### 차트 해석

## 📊 통계 공식

### 평균 (Mean)
```
μ = Σ(value) / n
```

### 표준편차 (Population Stdev)
```
σ = √(Σ(vi - μ)² / n)
```

### Z-Score
```
z = (현재값 - μ) / σ
```

### 표준편차 밴드
- **±1σ**: 약 68%의 데이터 포함
- **±2σ**: 약 95%의 데이터 포함

## 💾 데이터 구조

```javascript
{
  ticker: "AAPL",                    // 티커명
  years: [2021, 2022, 2023, 2024, 2025],
  per: [25.5, 24.2, 28.1, 26.3, 27.8],  // 역사 PER
  pbr: [35.2, 38.5, 42.1, 39.8, 41.2],  // 역사 PBR
  psr: [28.5, 31.2, 34.8, 32.5, 35.1],  // 역사 PSR
  currentPer: 29.5,                  // 현재 PER
  currentPbr: 44.5,                  // 현재 PBR
  currentPsr: 36.2,                  // 현재 PSR
  useConsensus: true,                // 컨센서스 사용 여부
  consensusPer: 28.0,                // 컨센서스 PER
  consensusPbr: 42.5,                // 컨센서스 PBR
  consensusPsr: 34.8                 // 컨센서스 PSR
}
```

- 다운로드된 .xlsx로 추가 분석 가능

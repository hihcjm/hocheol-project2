## 📝 첫번째 사용 단계

### 🚀 방법 1️⃣ : 미국 주식 (자동 데이터 조회) ✨ NEW

#### Step 1: 미국 주식 입력
```
입력 필드에 미국 주식 티커 입력
예) AAPL, GOOGL, TSLA, MSFT, META, NVIDIA
```

#### Step 2: 자동 조회
```
탭 또는 엔터 키 누르기
↓
"⏳ 데이터 조회 중..." 표시
↓
자동으로 현재 PER, PBR 조회 완료!
```

#### Step 3: 과거 5년 데이터 입력 (수동)
```
표에 5년간의 PER, PBR, PSR 값 입력
예)
연도 | PER  | PBR | PSR
2021 | 25.5 | 35  | 28
2022 | 24.2 | 38  | 31
... 계속 입력
```

#### Step 4: 저장
```
"💾 저장" 버튼 클릭
→ 자동으로 차트 생성 + 통계 계산
```

---

### 📝 방법 2️⃣ : 한국 주식 또는 수동 입력

#### Step 1: 종목 선택
```
입력 필드에 티커명 또는 종목명 입력
예) 삼성전자, 네이버, TSMC 등
```

#### Step 2: 데이터 입력 (모두 수동)
```
표에 5년간의 PER, PBR, PSR 값 입력
예)
연도 | PER  | PBR | PSR
2021 | 12.5 | 0.85 | 0.92
2022 | 8.3  | 0.62 | 0.71
... 계속 입력
```

#### Step 3: 현재값 입력
```
현재 PER, 현재 PBR, 현재 PSR 입력
예)
현재 PER: 10.2
현재 PBR: 0.78
현재 PSR: 0.62
```

#### Step 4: 저장
```
"💾 저장" 버튼 클릭
→ 자동으로 차트 생성 + 통계 계산
```

### Step 5: 결과 분석
```
3개 차트 확인:
- 과거 데이터 추이 (파란 선)
- 현재값 위치 (빨간 점)
- 평가 등급 표시

결과 카드 확인:
- Z-Score 및 평가 (저평가/적정/고평가)
- 게이지 바 (-2σ ~ +2σ 범위)
```

## 🔍 차트 읽기

### 색상 의미
```
파란 선 ───── 과거 5년 추이
빨간 점 ━━━━━ 현재값 (여기가 평가)
초록 점선 - - - 평균선 (중심)
주황 점선 - - - ±1σ (정상 범위)
빨강 점선 - - - ±2σ (극단 범위)
```

### 해석
```
현재값이 평균 위   → 고평가 (비싸다)
현재값이 평균 아래 → 저평가 (싸다)
현재값이 ±2σ 밖   → 극단적 (곧 평균으로 돌아올 가능성 높음)
```

## 🆘 문제 해결

### 차트가 안 나타남
```
1. 브라우저 새로고침 (F5)
2. 캐시 삭제 후 다시 시도
   → Chrome: Ctrl+Shift+Delete
3. 개발자 도구 (F12) 콘솔 확인
```

### 데이터가 저장 안 됨
```
1. 티커명이 입력되어 있는지 확인
2. 브라우저 설정에서 LocalStorage 허용 확인
3. 캐시 차단 설정 확인
```

### 엑셀 다운로드 안 됨
```
1. 팝업 차단 설정 확인
2. 다른 브라우저에서 시도
3. 브라우저 새로고침
```

### 반응형 디자인 확인
```
1. F12 개발자 도구 열기
2. 디바이스 에뮬레이션 ON
3. 다양한 해상도에서 레이아웃 확인
```

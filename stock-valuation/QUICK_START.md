# 🚀 빠른 시작 가이드 v2 - 한국 주식 자동 조회

## 📍 요약: 이제 한국 주식도 자동으로 조회됩니다!

**삼성전자(005930), 네이버(035420) 등**을 입력하면:
1. ✅ 5년 과거 PER/PBR/PSR 자동 조회
2. ✅ 현재 PER/PBR/PSR 자동 입력
3. ✅ 컨센서스 자동 조회
4. ✅ 즉시 차트 생성

---

## ⚡ 5분 안에 시작하기

### Step 1️⃣: Python 라이브러리 설치 (1분)
```bash
pip install flask flask-cors requests pandas
```

### Step 2️⃣: 서버 시작 (터미널)
```bash
cd C:\Users\yaho2\workspace\bucket-list-main\stock-valuation
python server.py
```

**출력:**
```
* Running on http://127.0.0.1:5000
```

⚠️ **중요**: 서버는 계속 실행되어야 합니다!

### Step 3️⃣: 앱 열기 (브라우저)
```
index.html 더블클릭 또는
http://localhost:8000 (다른 포트 사용 시)
```

### Step 4️⃣: 한국 주식 입력
```
입력: 005930  (삼성전자)
탭/엔터 키 누르기
↓
⏳ 데이터 조회 중...
↓
✅ 5년 데이터 자동 입력!
↓
💾 저장 버튼 → 차트 생성!
```

## ⚠️ 문제 해결

### 1️⃣ "로컬 서버가 실행 중이 아닙니다"
```
✅ 해결:
1. 터미널 열기
2. python server.py 입력
3. 앱 새로고침 (F5)
```

### 2️⃣ "주식 코드를 찾을 수 없습니다"
```
✅ 해결:
1. 코드가 정확한지 확인
2. 예: 삼성전자 → 005930 (반드시 숫자만)
3. 네이버 증권에서 다시 확인
```

### 3️⃣ "ModuleNotFoundError: No module named 'flask'"
```
✅ 해결:
pip install flask flask-cors requests pandas
```

### 4️⃣ 느린 속도 (3초 이상)
```
✅ 해결:
1. 인터넷 속도 확인
2. 네이버 증권이 응답 중일 수 있음
3. 몇 분 대기 후 재시도
```

### 5️⃣ 데이터가 일부만 나옴
```
✅ 해결:
- 회사가 제공하지 않는 지표일 수 있음
- 조회된 데이터 사용
- 없는 데이터는 수동 입력
```

## 🎓 어디에 데이터가 있나?

### 입력 테이블
```
연도 | PER  | PBR | PSR
─────┼──────┼─────┼────
2021 | 8.2  | 0.92| 0.65  ← 자동 채워짐
2022 | 7.5  | 0.85| 0.62  ← 자동 채워짐
2023 | 8.8  | 1.02| 0.68  ← 자동 채워짐
2024 | 9.2  | 1.05| 0.70  ← 자동 채워짐
2025 | 8.5  | 0.95| 0.65  ← 현재값 (자동)
```

### 현재값 행
```
현재 PER: 8.5   ← 자동 채워짐
현재 PBR: 0.95  ← 자동 채워짐
현재 PSR: 0.65  ← 자동 채워짐
```

### 컨센서스 (토글 ON 시)
```
컨센서스 PER: [목표가 기반 자동 계산]  ← 자동
컨센서스 PBR: [자동]
컨센서스 PSR: [자동]
```

## 💡 팁과 트릭

### Tip 1: 여러 주식 비교
```
1. 삼성전자 입력 → 저장
2. 네이버 입력 → 저장
3. SK하이닉스 입력 → 저장

사이드바에서 빠르게 전환!
```

### Tip 2: 엑셀 다운로드
```
분석 완료 후:
1. "📥 엑셀 다운로드" 클릭
2. stock-valuation-005930-2025-03-07.xlsx 저장
3. 엑셀에서 추가 분석!

Sheet1: 입력 데이터 (5년 수치)
Sheet2: 통계 결과 (평균, Z-Score, 평가)
```

### Tip 3: 차트 해석
```
현재값(빨간 점)이:
- 평균 위: 고평가 (매도 신호)
- 평균 아래: 저평가 (매수 신호)
- ±2σ 밖: 극단적 (평균 회귀 가능)
```

### Tip 4: 모바일 사용
```
스마트폰 브라우저에서도 가능!
- iOS Safari
- Android Chrome
- 데이터는 각 기기별로 저장됨
```
